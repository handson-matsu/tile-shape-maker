# タイル輪郭メーカー

中学生向けの、辺を切り取って移動・反転するタイル輪郭エディターです。

[アプリを開く（本人限定）](https://tile-outline-maker.kmatsu14531.chatgpt.site)

## 起動

依存パッケージやビルドは不要です。リポジトリのルートで実行してください。

```sh
python3 -m http.server 5173 --directory tile-app/dist
```

ブラウザで http://localhost:5173 を開きます。

## 機能

- 正方形・正三角形・正六角形
- 辺全体／前半／後半、対称／非対称、山型／谷型／台形／曲線
- 高さ：低い／ふつう／高い（初期値ふつう）。対称性とは独立し、変更時に切片・配置候補を即時更新
- 「反転しない／反転する」の2択。回転を自動的に含め、全辺と同じ辺の残り半分を探索
- 配置候補をクリック・タップして正確に配置。キーボードにも対応
- 複数回加工、元に戻す、やり直す、リセット（リセットや図形変更も取り消し可能）
- 白を含む7色のタイル色、白／黒背景、完成プレビュー、1200 × 1200 PNG保存（図形と背景のみ）
- PC・タブレット・スマートフォン対応

## 初期版の幾何仕様

加工対象は基本図形上の未加工の辺・半辺です。一度加工した部分の再加工は、履歴を戻して行います。自由描画・自由ドラッグ・敷き詰め可能性の判定は行いません。

切り取りは辺の内側、配置は未加工の辺の外側です。切り取り深さは選んだ区間の長さの19%を基準とし、低いは0.5倍、ふつうは1倍、高いは1.6倍です。高さは輪郭の法線方向だけに適用され、頂点位置や対称性を変更しません。確定した加工には高さ反映済みの輪郭を保存するため、その後の設定変更でも形は変わりません。曲線は32区間の折れ線で近似します。「反転しない」では始点と終点の対応を逆にし、回転と平行移動で切片を配置します（向き・表裏を保存）。「反転する」では始点と終点を順に対応させ、法線方向を反転する鏡映と必要な回転・平行移動を行います。どちらも全辺と、半辺切り取り時の元の辺の残り半分を探索します。独立した自己反転ボタンはありません。非対称の山型は頂点を区間の20%、曲線は最大の膨らみを25%に寄せています。

切り取り直後の輪郭も検査し、高い切り取りが別の辺を越える場合は配置候補を生成しません。配置前に、重複する加工区間、非隣接辺同士の交差・接触、面積変化を検査します。穴や離れ小島を持たない単純な多角形として輪郭を保持します。複数加工でも同じ検査を適用します。加工状態はページ内だけに保持し、再読み込みでは初期状態に戻ります。

PNGには選択したタイル色で輪郭の内側を塗り、背景を完全な白または黒で保存します。外周に余白を設けます。背景と同色でも見えるように、背景に応じた輪郭線をタイル領域の内側に描きます。色の選択は加工・Undo・Redo・Resetでも保持します。既存のタイルメーカー／敷き詰めアプリの実際の読み込み仕様は未提供のため、読み込み互換性は未検証です。

## 検証

```sh
node tile-app/tests/geometry.test.mjs
node tile-app/tests/height.test.mjs
```

全図形・全切り取り設定・全変換の候補と連続加工について、4,568配置を検証。輪郭の単純性、面積保存、切片の合同性、加工済み区間の拒否、同じ辺への候補、回転中の形状保存、鏡映時の向きの反転、および衝突候補を除外する回帰ケースを確認しています。

`@napi-rs/canvas` を利用できる環境では `node tile-app/tests/appearance.test.mjs` でPNGの全14配色（7色×2背景）の画素を検証できます。選択色・背景色・輪郭線を確認し、輪郭の外へ線がはみ出さないことも検査します。

高さ設定を含む12,952配置・連続加工について、形状と面積の保存、対称性との独立性、通常の高さとの互換性、高さによる衝突候補の除外を検証しています。

実装: `tile-app/dist/index.html`、`style.css`、`app.mjs`、`geometry.mjs`、`appearance.mjs`。
